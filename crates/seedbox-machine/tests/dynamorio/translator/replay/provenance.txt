Replay contract:
Required registered original-population runs use public drdecode: all50 saved
inputs each in a fresh process, and all eight full transform populations. Shared
public IR controls and selector controls remain registered in both decoder and
standalone modes. The standalone variants of the original-population executables
remain available as manual supplemental diagnostics, not required original-test
runs. They use dr_standalone_init/exit and the same SDK's actual core, including
Debug core assertions; their names end _standalone. Native host feature eligibility
can reject extension encodings accepted by the original transform decoder.

For a manual saved-input diagnostic, take each row's adapter and input path from
share/translator/replay/cases.tsv and run bin/translator_replay_<adapter>_standalone
with share/translator/saved/<input> as its sole argument, in a fresh process per
row. For the complete manual transform diagnostic, run
bin/translator_replay_ir_transform_standalone -seed 1 -n 400000 -created 40000
-ilists 8000 followed by every sorted path under share/translator/vectors/.
Use absolute paths under the prepared SEEDBOX_DYNAMORIO_FIXTURES root. Retain each
exit status, stdout and stderr and report failures explicitly, including host
feature limits; neither rejection nor unavailable features become success.
No emitted instruction needs execution. These diagnostics do not replace the
original custom drdecode_fuzz assertion/sanitizer/leak policy. Native ARM decoder
runs remain required; host offline decoding and cross-builds do not execute them.

Install executables under bin/translator_replay_*, metadata/licenses
under share/translator/replay. CMake configures matching public SDK targets and
retains the core library's own install RPATH; there are no test-time compilers,
downloads, assertion hooks, private headers or upstream test-runner dependencies.
The test driver runs all independent inputs and reports each original source ID.
Any unsupported required selector fails explicitly. Source rejection-or-faithful-
roundtrip rules are retained: arbitrary malformed encode requests may reject;
unmutated/renamed valid requests must encode. SYS aliases and logical-immediate
canonical forms retain their original specific equivalence checks, not generic
unsupported acceptance. Original syntax/VL, operand mutation, disassembly canary,
relocation, MOVN/MOVZ, effective-address and register-query oracles remain.

The source numeric selector population matters: source_register_names preserves
all 410 A64 enum values (including the five after FPMR). source_opcode_names preserves
source IDs 6..1232 including holes. The embedded MAX_ADDRESSING_REG alias
does not consume a numeric selector or change the source modulus. Runtime lookup maps scratch requests by source
opcode name; unsupported names fail. Missing original register names are resolved
through the public register-name API if a later SDK supplies them; otherwise they

explicit GPRs, never LAST_VALID+1 (which would lose original MPX/reserved values).

Private-layout adaptations:
Operand kinds use documented predicates. Element size uses the public accessor.
Register renaming is checked by an independent expected register/base/index map,
not by invoking the same replacement API to construct the expected operand.
For a zero-offset base-only operand, pre/post state is observed by inserting a
normalized copy into public LDR writeback IR and comparing its exact encoding.
Pre/post decoded 0xf8400c20/0xf8400420 controls must discriminate before the full
population. The instr_same exception replaces the memory operand only after all
other observable fields match. No private operand bits are read or written.
